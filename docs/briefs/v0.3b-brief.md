# Brief — v0.3b Multi-Panelist Orchestration

**Source of truth:** `docs/v0.3b-multi-panelist-orchestration-decisions.md` (LOCKED 2026-07-10). This brief is derivative — if anything here conflicts with the decision doc, the decision doc wins. Execute this brief only; do not add scope.

**Do NOT build:** adaptive turn retention / score-driven handoff (v0.3.x, gated on round-robin verification). Round-robin only.

---

## Task 1 — Add `answer_summary` to the scoring schema

- Extend the existing scoring call's output schema with `answer_summary`: 1–2 sentences summarizing what the candidate **claimed** (not a judgment — the claim itself).
- This rides on the **existing** scoring call. No new LLM call. Do not add a separate summarization step.
- Update the scoring system prompt to instruct the emission of `answer_summary` alongside the current fields. Bump `PROMPT_VERSION`.

## Task 2 — Structured digest (render-only, from session state)

- Implement a digest renderer that produces, per prior turn, chronologically:
  ```
  panelist_id
  persona_name
  question          (verbatim)
  answer_summary    (from Task 1)
  primary_gap
  score
  ```
- Rendered from session state → template string. **Zero LLM calls.**
- Cap at last N turns. Make N a single named constant (choose a reasonable default, e.g. 6) — not a magic number scattered inline. Do not design adaptive-N behavior.
- Inject the rendered digest into the active panelist's context on every turn, for **all** panelists (not just DA).

## Task 3 — Devil's Advocate persona

- DA selects the strongest / highest-scored prior claim from the digest's `answer_summary` fields and contests it, grounded in the source document.
- Persona template must state explicitly:
  1. DA contests **claims, never the candidate personally**.
  2. DA's grounding_reference points at the **source document**, same rule as everyone.
- DA output passes through `is_grounded()` unchanged — **no adversarial exemption**.
- (No difficulty-4/5 probe work in this brief — that's the hardening session. Just don't build an exemption that would block it later.)

## Task 4 — Round-robin turn-taking, DA last

- Fixed rotation, one turn per panelist per round.
- **DA sits last** in the round.
- No score-driven handoff, no floor retention. Fixed order only.

## Task 5 — Miss 2 fold-ins

- **Prompt fix:** add one sentence to `FOLLOWUP_SYSTEM_PROMPT` — `grounding_reference` must quote the **source document**, never the candidate's answer. Bump `PROMPT_VERSION` (coordinate with the Task 1 bump — single version increment for the 0.3b template set).
- **Relabel:** in `docs/v0.2-eval-results.md`, change the Miss 2 "(b) fabrication" label to: "fabrication *with respect to the chunk* — reference is the candidate's own answer, a follow-up-path field-misuse, distinct from difficulty-4 content fabrication."

## Task 6 — Engine/UI loop extraction

- Extract the turn loop into a standalone **engine module**.
- `main.py` and `streamlit_app.py` become thin drivers that call the engine.
- The engine must be runnable headless (CLI driver) with no Streamlit import in the engine path — this is what gives the hang investigation its bisection point.
- **Do not** attempt to fix the Streamlit hang in this brief. Extraction only. If the extraction incidentally surfaces the hang, note it in the review, don't chase it.
