## What the run found

The first attempt failed at `GET /quota` with 503 "waking up", and a rerun seconds later worked.
Neon had suspended and left the pool's connections dead.
That's fixed: the pool now checks a connection on checkout and replaces a dead one (decisions doc, item 14).
The script also retries `/quota` on a 503.

The live `X-Forwarded-For` check showed Render's chain is three proxies deep, not one, so the per-IP limit would have put every visitor in one bucket.
`ADS_TRUSTED_PROXY_HOPS` is 3 in Render and now 3 by default (decisions doc, item 12).
